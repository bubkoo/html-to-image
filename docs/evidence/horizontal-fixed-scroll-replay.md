# Horizontal fixed descendant regression

The shared fixture is `test/browser/fixtures/horizontal-fixed-scroll.mjs`. Its 12 modes construct a 40×40 horizontal flex viewport and place a blue fixed stripe in the actual source at x=4 using the browser-reported containing block. A screenshot taken **before capture** must contain blue at x=6 and green at x=20. The absolute-descendant case also requires purple at x=14. This is a setup control, not an expected image generated by the library.

Run the native-source and capture assertions in all three engines:

```sh
pnpm exec vitest run --config vitest.browser.config.mts test/browser-unit/horizontal-fixed-scroll.test.ts test/browser-unit/fixed-scroll.test.ts
```

For the recorded baseline comparison, only `src/clone-scroll.ts` was the unmodified parent revision `4d1bd59a33109657b875c40cfffa9f206f6cb13e`; the final shared fixture and test file were identical. All 36 source controls passed, followed by 33 capture failures and three existing-wrapper positive controls. Candidate plus existing fixed tests passed 126/126. Restore source files in `finally` if replaying this comparison in a checkout containing unrelated work.

`test/browser/smoke.html` runs all modes through built ESM and UMD. The complete package suite includes that case and the full smoke page in each engine. The independent `local-deep` source/capture PNGs compare every RGBA channel; see the JSON for exact hashes and results. These PNGs supplement the per-case assertions; they do not broaden the supported layout contract.

The change applies to horizontal-tb, single-line row/row-reverse flex layouts without anonymous text items, display:contents items, auto side margins or sticky descendants. Opposite physical side margins keep each item’s main-axis outer size unchanged and create no containing block. Positioned descendants are adjusted only if their **source** offsetParent is the original scroller. Diagonal and broader scroll layouts remain separate work. Real-device and remote status are recorded explicitly in the JSON.
